About the Project 

My motivation : According to research about 6% of the world's population are deaf or mute. However, the available sign language translator are only 60, which is far below the requirement 
Sources: https://www.thestar.com.my/lifestyle/living/2025/10/02/only-60-interpreters-for-44000-deaf-malaysians---why-the-community-struggles 

About the Project
Sign-tifically Speaking is a computer vision project combine with deep learning that can recognize sign language gesture through webcam and convert them into text and audio prediction 

Objective
1. detect keypoint on hand using MediaPipe
2. Train a Machine Learning and Deep Learning Model to make prediction
3. Evaluate model's performance and make adjustment
4. build an interphase to allow user to learn and detect sign language themselves
5. Hardware output? Will take into consideration LOL SEE HOW

Project Workflow 
Real time web cam input --> Hand Landmark Detect ---> Processing --> Sign Language Interpretation --> Text and Audio Prediction
